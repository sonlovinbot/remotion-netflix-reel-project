# Danh mục asset của dự án mẫu

Toàn bộ asset nằm trong `project/public/assets` và được commit vào Git.

| Thư mục  | Nội dung                                   |
| -------- | ------------------------------------------ |
| `audio`  | Voice-over tiếng Anh và tiếng Việt         |
| `cta`    | Ảnh Sơn trong studio và voice-over CTA     |
| `scene1` | Cửa hàng, nhân vật trẻ, khung ảnh, mây     |
| `scene2` | Nhân vật Blockbuster, tay, tiền, khói      |
| `scene3` | Bàn và ba trang báo                        |
| `scene4` | Nhân vật thất bại, biển đóng cửa, dây khóa |
| `scene5` | Nhân vật trưởng thành và địa cầu           |
| `scene6` | Ảnh nhân vật cuối đã tạo lại               |
| `shared` | Nền, texture, logo dùng chung              |

## Quy ước khi thêm asset

- Tên file dùng chữ thường và dấu gạch ngang.
- Đặt file vào đúng scene.
- Asset dùng nhiều scene đặt trong `shared`.
- Không ghi đè ảnh cũ khi đang thử nghiệm; dùng hậu tố `-v2`.
- Audio nên là WAV hoặc MP3 rõ tiếng, có khoảng nghỉ tự nhiên.
