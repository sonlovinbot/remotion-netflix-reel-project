# Checklist asset

Trước khi dựng, kiểm tra:

- [ ] Ảnh đủ rõ và đúng tỷ lệ khung hình.
- [ ] Nhân vật nhất quán giữa các scene.
- [ ] Logo có nền trong suốt nếu cần.
- [ ] Voice-over là bản cuối, không còn câu đọc sai.
- [ ] Nhạc nền không lấn giọng đọc.
- [ ] Tên file ngắn, dễ hiểu, không dùng tên như `final-final-2`.
- [ ] Đã xác minh quyền sử dụng asset.
- [ ] Mọi file cần thiết đều nằm trong `project/public/assets`.
- [ ] Không có mật khẩu, API key hoặc dữ liệu riêng tư trong asset.
